Deprecated components

The components listed on this page are deprecated. They still ship with @czi-sds/components and their stories are kept in this section so that existing usages can be read and migrated, but every one of them has a supported replacement and will be removed in a future major version.

Warning: Do not use these components in new work. A deprecated component receives no new features or design updates, and its eventual removal is a breaking change you would have to absorb later. Reach for the replacement instead.


What to use instead

Each deprecated component repeats this guidance in a callout on its own story. The table below collects it in one place.
