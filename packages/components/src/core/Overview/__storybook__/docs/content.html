Components

The components of the Science Design System: accessible React building blocks built on Material UI and themed with the SDS design tokens.

The main package: everything in this section ships as @czi-sds/components, which carries both the components and the theme they read their colors, spacing and typography from. That theme is why the rest of the system depends on it: @czi-sds/data-viz requires it at runtime, and an app installs it whether or not it ever imports a chart.

The pages in this section are the code half of the documentation: props, examples and stories to play those props against. The design guidance behind each component, and the reasoning for it, lives under Design Documentation.

Usage

@czi-sds/components comes with five main exports that help you build your app.

1. Components: accessible and reusable components.

2. Mixins: grouped styles defined by the design system.

3. Selectors: helper functions that read theme variables from the passed props.

4. CSS and SCSS variables: for apps that do not use @emotion/styled.

5. Tailwind config: a Tailwind-compliant version of the design tokens.
