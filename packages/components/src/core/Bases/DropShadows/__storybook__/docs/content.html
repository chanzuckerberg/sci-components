Drop Shadows

Four shadows for four heights above the page, from flat content to a modal covering it.

Source Code

The tokens behind these values can be found in drop-shadows.json .

Usage

getShadows reads them off the theme, and each one is a complete box-shadow value. Every shadow is also published as a CSS and SCSS variable.
