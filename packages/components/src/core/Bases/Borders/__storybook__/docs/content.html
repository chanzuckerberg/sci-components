Borders

Complete border shorthands, grouped by intent and then by state, in colors that follow the theme.

Source Code

The tokens behind these values can be found in borders.json .

Usage

getBorders reads them off the theme. Every token is also published as a CSS and SCSS variable, which is what to use in an app that does not style with Emotion.
