Borders

Borders are the lines that go around elements to help contain them while visually communicating to users an element's usage, status, or intent.

Types of Borders

Visual

Border Type

Usage

Standard Border

Base style for all borders. Borders are used on secondary buttons, input fields, modals, dropdown menus, etc.

Dashed Border

Dashed borders are used in file upload/drag and drop containers and Dashed Links .

Base Borders

These borders are used throughout the SDS whenever borders in Base colors are needed.
