Buttons

Buttons are one of the primary ways users interact with and provide input to the product's UI, serving as the main elements to solicit user action.

Button Components

There are a range of Button types available to use depending on the amount of emphasis the Button needs to have, its location in the UI, and whether it is existing alone or alongside other Buttons.

Button – Minimal

Minimal Buttons initiate actions that keep the user on the same page, such as opening or closing Dialogs . They should contain a maximum of 2-3 words.

If a longer or inline call to action with a similar visual style is needed, a Link might be more appropriate. In addition to containing more words, Text Links navigate the user away from their current page to a new one, whereas Minimal Buttons keep users on the same page.

Use for primary or emphasized actions.

Overview

Use Toggle Button when there is a need to enable or disable an element in the UI (such as toggling visibility of a Panel ). If users need to indicate true or false as part of a form or flip a setting or option from off to on (and vise versa), use Toggle Input .

Optionally, pair Toggle Button with a Tooltip to use as a label to communicate the button's functionality.

Toggle Button – Primary should be used in places that require the user's primary attention or to emphasize a primary action. Can be paired with other Button components.
