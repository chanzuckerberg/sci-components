Science Design System

The Science Design System supports the products and experiences that comprise CZI's suite of science applications. The system consists of design specs, components, resources, and working code, providing structure and guidance for anyone contributing to CZI's science products.

Every component in the library, grouped by what it is for. Each card is the component's own example running live, and leads to its documentation: the props it takes, the patterns it belongs to, and code you can copy. New here? Start with the Introduction or Getting Started.
