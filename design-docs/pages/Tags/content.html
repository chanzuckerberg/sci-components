Tags

Tags communicate a status related to the element they are paired with. Chips show which conditions, such as filters or search parameters, the user has applied to a dataset.

Tag Components

There are two components. The Tag labels an element or communicates a status associated with it, and can be used throughout the UI. The Chip (TagFilter in code) is used together with Filters to show which conditions have been applied, and the user removes a condition by clicking its Chip.

Overview

  • Tags can be used throughout the UI to communicate conditional statuses related to the elements they are paired with.

  • Tags can optionally function as links that navigate to a new page when clicked. This is not a separate type, but the same type with that functionality enabled. In code, a Tag becomes a link by being given a URL, and an optional arrow icon can communicate that the Tag has an embedded link. In Figma, the arrow icon can be toggled on or off; it is optional, and the Tag can function as a link without it.

  • When paired with Chips or Toggle Buttons, Tags can communicate which elements within the UI the Chip or Toggle Button is affecting, such as which elements a filter condition is being applied to. This is indicated by shifting the affected Tags to the beginning of the list of other Tags.

  • To return a Tag to its default position in a list of other Tags, users must remove the Chip or toggle off the Toggle Button that Tag is paired with. Clicking on a Tag does not remove the corresponding Chip or toggle off the corresponding Toggle Button.

Tag Styles

There are two styles. Solid fills the Tag with the intent color and is the stronger of the two. Outline uses a tinted fill with the label, icons and a thin border in the intent color, for Tags that should sit back in a busy layout. Both are shown below with text, text with an icon, the link arrow, and an icon on its own.

Sizes and Content

Tags come in medium and small. Use medium by default, and small where space is tight, such as in navigation or beside a tab's label. Each size can hold text, text with an icon, or an icon alone.

Note: The icon-only variant is square, with cornerM (4px) corners, whereas the text and text with icon variants are pill-shaped, with cornerRounded (20px) corners. An icon-only Tag still needs a label in code, which screen readers read; pair it with a Tooltip that shows the label to sighted users.

Tag States

A Tag that does something when clicked, such as a link or a Tag that filters, has default, hover, pressed and disabled states. A Tag that only labels something stays in its default state and does not respond to the pointer.

Chip

  • In Figma
  • Meets Accessibility
  • In Code

Overview

The Chip is used exclusively to communicate that the user has applied a condition to a dataset or collection of information, such as a filter or a search parameter. Users remove a Chip by clicking on it. It comes in the same solid and outline styles as the Tag, always in the Accent intent, with default, hover and pressed states.
