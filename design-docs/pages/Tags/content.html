Tags

Tags are used to label the status of certain elements or in conjunction with filters to indicate which have been applied when viewing datasets.

Tag Components

There are two types of Tags: standard and filter. Filter Tags are used in conjunction with the Filter component to indicate which filters have been applied to a given dataset. Standard Tags come in two styles, Rounded and Square, and can be used throughout the UI whenever there's a need to label an element or communicate a status associated with it.
